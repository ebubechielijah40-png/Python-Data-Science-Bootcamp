# Lesson 01: Resources

External references only. Use these to go deeper or when you're stuck
and need a second explanation.

## Official Documentation

- NumPy official Quickstart guide: https://numpy.org/doc/stable/user/quickstart.html
- NumPy full API reference: https://numpy.org/doc/stable/reference/index.html

## Beginner-Friendly Tutorials

- W3Schools NumPy tutorial: https://www.w3schools.com/python/numpy/default.asp

## Practice

- Search "NumPy exercises" on GitHub for community-built practice
  problem sets once you've finished this lesson's classwork and
  assignment.

## When You're Stuck

- Read the exact error message out loud, top to bottom, before
  searching anything.
- If you do search, search the exact error text plus "numpy" — the
  official documentation and Stack Overflow answers for common NumPy
  errors are usually accurate and specific.
