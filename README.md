
# Python Data Science Bootcamp

This repository contains a professional, four-week Python for Data Science bootcamp designed for motivated adult learners.

Course duration: 4 weeks (20 lessons), 2 hours per lesson, 5 lessons/week.

Follow the folders under the repository for lesson content. Each lesson folder contains the required files and follows the lesson structure in the master specification.

To run examples for a lesson, open the lesson folder and run:

    python examples.py

To run the smoke tests locally (if you've installed pytest and requirements):

    pytest -q

See the Day 1 folder for an example lesson and usage.
